# Armandinho Fan Page

## Sobre o Projeto

Este projeto é uma página web desenvolvida inteiramente em HTML com o objetivo de apresentar informações sobre o cantor Armandinho, um dos principais nomes da música reggae brasileira. A página reúne conteúdos relacionados à sua trajetória, carreira musical e importância no cenário da música nacional.

O projeto foi criado como uma forma de praticar os conceitos fundamentais de HTML, aplicando técnicas de estruturação de conteúdo e organização de informações em uma página web simples e informativa.

## Funcionalidades

- Apresentação de informações sobre o cantor Armandinho.
- Exibição de dados sobre sua carreira e trajetória musical.
- Estrutura organizada para facilitar a leitura e navegação.
- Conteúdo informativo voltado para fãs e admiradores do artista.
- Desenvolvimento realizado exclusivamente com HTML.

## Tecnologias Utilizadas

- HTML5

## Objetivo

O principal objetivo deste projeto é praticar os fundamentos do desenvolvimento web utilizando HTML, por meio da criação de uma página temática dedicada ao cantor Armandinho, apresentando informações relevantes sobre sua carreira e sua contribuição para a música brasileira.

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos fundamentais de HTML, incluindo:

- Estruturação de páginas web.
- Organização de conteúdo textual.
- Utilização de títulos, parágrafos e listas.
- Criação de uma hierarquia visual para apresentação de informações.
- Boas práticas de marcação HTML.

## Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/Cantor-Favorito.git
```

2. Acesse a pasta do projeto:

```bash
cd Cantor-Favorito
```

3. Abra o arquivo `index.html` em qualquer navegador de sua preferência.
